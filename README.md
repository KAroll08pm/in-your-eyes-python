# In Your Eyes ♡

A tiny universe made with Python.

An animated heart with a pulsing effect and
twinkling stars, built using Python and Tkinter.

## Features

- Animated heart with a breathing effect
- Twinkling stars
- Dark, dreamy background
- No external Python packages required

## Requirements

- Python 3
- Tkinter

## Run

```bash
python3 main.py
```

On Debian or Ubuntu, if Tkinter is missing:

```bash
sudo apt install python3-tk
```
